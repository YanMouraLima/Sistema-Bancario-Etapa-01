# Sistema-Bancario-Etapa-01
Implementação de um Sistema de Registro e Gestão de Contas Bancárias (ETAPA 1).  
O programa permite ao usuário interagir com um menu que possui 6 itens e permite o cadastro de apenas um cliente.   
1 - Cadastrar conta  
2 - Consultar conta           
3 - Verificar saldo          
4 - Alterar tipo da conta      
5 - Ativar/Desativar conta  
6 - Sair
